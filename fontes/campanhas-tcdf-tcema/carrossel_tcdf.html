O que pouca gente aproveita03 / 07
A forma da Informação vale ponto
Só a peça segue o Manual de Redação Oficial do TCDF. E a moldura é fixa: dá para decorar.
0 a 6
Quesito só para os dados do processo no espelho de 2023
0 a 3
Quesito só para o desfecho: sugestões, fecho e signatário
Atenção
O signatário é “NOME” e “CARGO”, escritos assim. Seu nome no texto definitivo é marca de identificação e anula a prova.
Fonte
